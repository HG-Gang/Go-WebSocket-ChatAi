1. 连接配置

中转 URL 和 Key 会作为本次本地 WebSocket 连接参数发送到 Go 服务，由 Go 服务连接第三方上游；浏览器不会直接连接第三方上游。支持填写 https/http 地址，后端会自动转换为 wss/ws；但第三方必须支持 Realtime WebSocket 协议，普通 Chat/Completions HTTP 接口不能直接变成长连接。API Key 不会自动保存，且仅限开发调试；生产环境默认禁用 query key，请改用服务端配置。
